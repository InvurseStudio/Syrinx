# Summarize a document

Use the document attached to the message. If the user names a file instead, read it with `read_file`.

Write:

1. **In short:** two or three sentences on what the document is and its main conclusion.
2. **Key points:** five to eight bullets, in the document's order, each one line.
3. **Decisions and numbers:** decisions made, dates, amounts and figures that matter. Copy numbers exactly.
4. **Action items:** who needs to do what, by when, if the document says. Leave this section out if there are none.
5. **Open questions:** anything unclear, missing or contradictory. Leave this out if there is nothing.

Rules:
- Only include what the document says. Don't add outside facts or opinions unless the user asks for them.
- When you quote, use quotation marks and keep the exact wording.
- If only part of the document was available (for example a long file that was cut short), say which part you summarized.
- Match the length to the document: a one-page memo gets a few lines, not five sections.
